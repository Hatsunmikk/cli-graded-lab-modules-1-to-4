ii) Hardlink Creation -

iii) Symbolic Link Creation -
command : ln -s ~/sample_data.txt ~/sample_soft.txt
output description: A symbolic link named sample_soft.txt was created pointing to sample_data.txt.
output explanation: This command creates a symbolic link that stores the path to the original file. Unlike a hard link, it does not share the same inode.
